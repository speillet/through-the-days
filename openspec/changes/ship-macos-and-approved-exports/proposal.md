# Prepare wider Mac distribution and approved aggregate exports

## Why

Once personal use is reliable, the application can be prepared for wider Mac distribution and deliberate sharing of selected aggregates.

## What Changes

- Deliver milestone 6 (README phase 6, excluding backups already advanced into milestone 1).
- Verify a distributable app/disk image and a private-by-default export path with exact preview.
- Add private-content portability separately from public aggregates and already-required encrypted backups.
- Keep the proposal and its tasks visibly unimplemented until verification.

## Capabilities

### New Capabilities

- macos-distribution: Supported Mac packaging, release verification, and distribution constraints.
- approved-exports: Previewed, explicitly approved aggregate output for Hugo.
- private-data-portability: Deliberately selected private Markdown/JSON/PDF/CSV export and identity-preserving JSON import.

### Modified Capabilities

None. The delivered capability inventory is currently empty.

## Impact

Dependencies: The relevant product milestones and verified personal-use backup/restore.

Sources: README §§3, 10, 13 phase 6, 17.3, 19–20; appendix INT-10 (§12); decisions D-001 and D-005.

Out of scope: Automatic blog publication, exporting private prose by default, claiming all Mac architectures are supported without verification, or redesigning backup policy.

Open decisions: Resolve O-007 and exact aggregate allowlist/destination before distribution or export implementation.

Status: draft planning baseline derived from the README and recorded user decisions; no application implementation is claimed.
